# MeetingAssistant 智能会议管理 · 需求说明

> 所属模块：egis-agent-frontend → Playground → MeetingAssistant
> 后端依赖：egis-training-agent（meeting_agent）
> 版本：v1.0

## 一、背景与目标

企业年金培训场景下，培训管理员与学员需要频繁地查询、预定、取消会议室，并接收会议提醒。
传统方式依赖人工登记与口头通知，存在信息不同步、冲突不可见、提醒不及时等问题。

本功能将「会议管理可视化页面」与「会议智能助手（Agent 对话）」合并在 Playground 的一个功能面板中，
让用户既可以通过表单完成精确操作，也可以用自然语言一句话完成查、订、取消，并获得实时的会议提醒推送。

## 二、用户角色

| 角色          | 说明                   | 主要诉求                         |
| ------------- | ---------------------- | -------------------------------- |
| 培训管理员    | 组织培训课程与复盘会议 | 快速筛选可用会议室、批量管理预定 |
| 普通学员/员工 | 参与会议、临时发起会议 | 用自然语言快速查房、订房、取消   |

## 三、功能需求

### 3.1 会议室筛选查询

- 按「日期 + 开始/结束时间」查询该时段会议室占用情况
- 按「人数」过滤容量不足的会议室
- 按「设备」多选过滤：投影、白板、视频会议、电话会议
- 结果卡片展示：名称、楼层/位置、容量、设备标签
- 状态区分：`可预定`（绿）/ `已占用`（红），已占用时展示冲突会议的主题与时间段
- 顶部汇总「N 间可用」

### 3.2 会议预定

- 入口：顶栏「预定会议」按钮、会议室卡片「预定」按钮（已占用不可点）
- 表单字段：会议主题、会议室（下拉选择，默认当前筛选结果第一间）、日期、开始/结束时间、组织人、参会人（逗号分隔）、提醒时间（提前 5/15/30 分钟）
- 预定成功后：全局刷新会议室与预定列表
- 预定失败：展示后端返回的具体错误（如时间冲突）

### 3.3 会议预定管理

- 列表展示所有 `booked` 状态会议：日期、时间段、主题、编号、会议室、组织人、参会人
- 支持单条取消（二次确认），取消后自动刷新并同步提醒系统

### 3.4 会议智能助手（对话式交互）

- 悬浮入口：面板右下角 FAB 按钮，展开对话面板
- 快捷指令：查会议室、查预定、取消会议
- 自然语言支持：如「帮我查一下明天上午 9 点到 10 点能容纳 16 人、有投影的会议室」「帮我取消产品复盘会」
- 流式输出：Agent 回答逐字增量渲染，支持 Markdown（标题/列表/表格/代码块）
- 会话保持：同一次打开面板内保持 session，上下文连续
- 每轮对话结束后自动刷新会议室与预定数据（Agent 操作与页面状态保持一致）

### 3.5 会议提醒与实时通知

- 会议临近时由后端触发提醒（提前 N 分钟，随预定配置）
- 前端通过 SSE 长连接实时接收新通知，自动在对话面板中展示提醒卡片
- 页面加载时补拉未读通知，避免断线期间遗漏
- 已被取消的会议对应的提醒自动标记已读，不再弹出

## 四、非功能需求

| 项       | 要求                                                       |
| -------- | ---------------------------------------------------------- |
| 响应性能 | 会议室查询 ≤ 1s；Agent 流式首字 ≤ 2s                       |
| 实时性   | 通知推送延迟 ≤ 3s（SSE）                                   |
| 兼容性   | Chrome/Edge 最新两个大版本                                 |
| 降级策略 | Agent 不可用时页面表单功能不受影响，对话区展示明确错误提示 |

## 五、功能架构（需求视角）

- **需求层**：会议室信息不同步 / 预定冲突不可见 / 提醒靠人工
- **功能层**：筛选查询、会议预定、预定管理、智能助手对话、提醒推送
- **支撑层**：会议室资源服务、预定服务、meeting_agent（AGUI 流式）、通知服务（SSE）
- **输出层**：会议管理可视化面板、对话式问答、实时提醒卡片

## 六、验收标准

1. 按筛选条件查询，返回结果的可用/占用状态与冲突信息正确
2. 预定成功后列表即时出现新记录；取消后即时消失
3. 助手对话可完成「查会议室、查预定、取消会议」三类意图，回答包含结构化结果
4. 会议临近提醒在 3 秒内以卡片形式出现在对话面板
5. 后端停用时，页面展示错误提示且不崩溃
